# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **private vulnerability reporting** on the affected repository (Security tab, "Report a vulnerability"). Include what you found, how to reproduce it, and the version or commit.

You will get an acknowledgement, and we will keep you updated until it is resolved. Please give us reasonable time to fix an issue before disclosing it.

## Scope

In scope: the code in this organisation's repositories, including the hook handlers, daemon, MCP server and CLI. A local trust boundary matters here: see the [threat model](https://github.com/RyeDB/core/blob/main/docs/THREAT-MODEL.md) for what the project does and does not claim to protect.

## Supported versions

The project is pre-release. Only the `main` branch receives fixes.
